# RUNERGY · Daily Inbound Verification

润阳 · 每日入库核验

一个在浏览器本地完成库存对账的网页版看板。导入系统库存和每日现场扫描文件后，按 `SKU + 库位` 聚合，自动识别盘盈、盘亏、未扫描和系统缺失，并导出 Excel 纠正清单。

## 支持的文件

- `.xlsx`、`.xls`、`.csv`
- SKU 列可命名为：`SKU`、`商品编码`、`物料编码`、`货号`、`条码`
- 名称列可命名为：`商品名称`、`物料名称`、`品名`、`name`
- 库位列可命名为：`库位`、`仓位`、`货位`、`location`
- 数量列可命名为：`数量`、`库存数量`、`实盘数量`、`盘点数量`、`qty`

数据只在用户浏览器内解析，不上传到服务器。

## 扫描表格式

在「Daily Physical Scan / 每日现场扫描」导入 Excel 或 CSV。支持两列 `location` / `box NO`，也支持 `库位` / `箱号`、`位置` / `箱号`，列顺序可以互换。原有 `Scanned Location` / `Scanned Box N.` 格式继续可用。库位留空时沿用上方库位，重复箱号保留用于重复扫描检查。多工作表文件优先选择「库位箱号」主表；否则选择最后一个有效扫描表，并排除备注、范围外记录等辅助页。右上角可手动切换工作表，并显示各页记录数。箱号请保存为文本，保留前导零和长编号。

## 客户对应与箱号查询

将客户工单 Excel / CSV 拖入第 03 个上传区域，选择工作表、表头行，以及客户和箱号／工单号列。客户表只包含工单与客户也可导入，功率、品级为可选项。核对预览后点击「建立客户对应表」。每次导入替换当前对应表，刷新页面后需重新导入。

表中有箱号时按完整箱号匹配；仅含工单号时，先上传含箱号、库位和工单号的系统箱信息进行关联。功率优先读取系统箱信息的「功率档」，品级优先读取「箱等级」，因此同一工单下的不同箱号可以显示各自的功率与品级。不会从箱号猜测工单或客户。请把箱号和工单号保存为 Excel 文本，避免前导零或长数字精度丢失。

在查询框粘贴一个或多个箱号，支持换行、空格、制表符及中英文逗号分号。结果自动显示客户、功率、品级与工单号；未找到、信息不完整和冲突均单独标记，冲突保留不同对应记录。表格在当前浏览器页面内处理，不会随 GitHub 同步。

客户查询区域使用英文主文、中文小字。点击 `Download Excel / 下载全部查询结果` 下载所有页的查询结果（包含未找到及冲突记录），Excel 使用中英文列名，箱号与工单号保留为文本。没有查询结果时下载按钮禁用。

查询逻辑测试（Node 22.13+）：`node --experimental-strip-types --test tests/customer-data.test.mjs`。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 部署到 Vercel

把仓库导入 Vercel，Framework Preset 选 `Next.js`，保持默认构建设置即可。若 Vercel 对 vinext 兼容层有特殊要求，也可以把同一仓库作为静态/Cloudflare Worker 项目发布；当前正式版本由 OpenAI Sites 托管。
